# Client Requirements

## Core principle

The prototype must simulate the real operation.

It is not only a visual prototype.

It must preserve:
- business rules
- navigation
- scripts
- validations
- workflows

## Visual identity

The IMP platform must maintain the current visual identity.

Do not redesign.

## Module behavior

Discagem Automática must open inside IMP.

The user must navigate between modules without leaving the platform.

## Objective

The prototype must represent the future product behavior before backend development.
